# 油站网点地图管理

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Element Plus、Leaflet
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

这是一个功能最小闭环前端项目，数据默认保存在浏览器 localStorage 中，方便后续扩展接口、权限、图表或地图能力。

## 新站选址占用

在网点页下方的「新站选址占用」区录入站点名称、区域、经纬度（可点「从地图取点」在 Leaflet 地图上点选）和拟营业日期，加入候选后执行**整批预检**：

- **拒绝规则**：同区域已有三座营业站（营业中 + 待建名额已满 3 个），或与任一「营业中」站点直线距离不足 5 公里（Haversine 大圆距离）。暂停营业 / 库存紧张不计入营业站。
- **通过**：候选 → 待建，占用所在区域名额；候选不占名额。
- **取消待建**：立即释放名额，转回候选。
- **逾期未开业**：拟营业日期早于当天仍是待建的站点，打开页面时及每 30 秒巡检自动转回候选并释放名额。
- 待建站可「确认开业」转为营业中。

地图按状态着色（营业中 / 暂停营业 / 库存紧张 / 待建 / 候选），随顶部区域筛选同步；区域名额指标、候选与待建列表均响应同一份数据。所有变更经深度 watch 写入 localStorage（键 `hxwlfront-21-station-map`），刷新后保留，并对旧版本无坐标的种子数据做迁移补点。

业务代码按职责拆分：

| 文件 | 职责 |
| --- | --- |
| `src/business/sitingRules.ts` | 选址判定：距离计算、录入校验、区域名额与 5 公里预检 |
| `src/business/sitingFlow.ts` | 状态流转：整批预检、取消、开业、逾期回收 |
| `src/business/stationStore.ts` | 持久化：localStorage 读写、迁移、模块级单例 store |
| `src/components/StationMap.vue` | Leaflet 地图标记、取点与筛选联动 |
